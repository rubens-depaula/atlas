# Atlas

Atlas é um projeto pessoal de longo prazo criado para reunir estudos, experimentos e soluções desenvolvidas ao longo da minha jornada como desenvolvedor.

## Objetivos

- Aprender novas tecnologias na prática
- Construir aplicações úteis
- Centralizar automações e ferramentas pessoais
- Evoluir continuamente a arquitetura do projeto

## Tecnologias (planejadas)

- Java
- Spring Boot
- PostgreSQL
- Docker
- REST API
- GitHub Actions
